# SpendWise Budget Tracker

## Project Description

SpendWise is a simple budget tracking application designed to help users manage their budget and expenses.

The project was originally created as a visual budget tracker using HTML and CSS. In Week 6, JavaScript was added to make the application process and work with budgeting data.

The JavaScript allows the application to collect user input, store budgeting information, perform calculations, use reusable functions, and display results in the browser console.

## JavaScript Concepts Implemented

The following JavaScript concepts were implemented in this project:

- Variables
- Data types
- User input
- Number conversion
- Calculations
- Functions
- Console output
